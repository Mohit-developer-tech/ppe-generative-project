Model Scope & Research Limitations

Single Item Crops Only (Not Scene Detection)

The autoencoder operates strictly on pre-isolated crops. It does not perform spatial object detection or bounding box proposal generation on entire job-site images.

Severe Class Imbalance

Safety violations (head, N=867) comprise only ~3% of the training dataset vs. 15,991 helmets. While balanced weighting helps, violation recall remains at 69.63%.

L2 Reconstruction Smoothing

Pixel-wise MSE loss naturally penalizes sharp deviations, leading to slight blur on high-frequency textures like thin retro-reflective strips on vests.

Relative, Uncalibrated Scores

Decision values from the SVM are converted to percentage bars via softmax over hyperplane distances for interpretability, but should not be treated as Bayesian posterior probabilities.
