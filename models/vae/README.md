# Conditional VAE (cVAE) PPE Generation

Owner: @KhOmkar

## Overview
Conditional Variational Autoencoder (CVAE) for class-controlled PPE crop generation (head, helmet, vest) and smooth latent space interpolation.

- **Notebook**: `vae_conditional.ipynb`
- **Design Review**: `docs/vae_design.md`
- **Trained Artifacts**: `results/cvae/` (`cvae_best.pt`, `model_config.json`, `cvae_metrics.json`, figures)
- **Dashboard Service**: `dashboard/models/cvae/`
- **Active Branch**: `feature/vae`

## Contribution Guidelines
Pull requests that touch only `/models/vae/` can be merged after one review from `@KhOmkar`. Pull requests modifying `/common/` or `/dashboard/` require approval from `@Mohit-developer-tech`.
