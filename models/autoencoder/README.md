# Autoencoder + SVM PPE Baseline

Owner: @Mohit-developer-tech

## Overview
Convolutional Autoencoder baseline with downstream Support Vector Machine (SVM) classifier for 64x64 PPE crop verification.

- **Notebook**: `01_autoencoder_svm.ipynb`
- **Trained Artifacts**: `results/autoencoder/` (`ae_best.pt`, `scaler.joblib`, `svm_model.joblib`, `class_names.json`, `model_config.json`)
- **Dashboard Service**: `dashboard/models/autoencoder/`

## Contribution Guidelines
Pull requests that touch only `/models/autoencoder/` require one peer review to merge. Changes touching `/common/` or `/dashboard/` require approval from `@Mohit-developer-tech`.
